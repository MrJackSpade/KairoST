# v1.4.5

- Manage library creates a new game on a blank floppy.
- Stretch scaling fills the whole screen, ignoring the picture's aspect ratio, on both screens of a dual-screen device.
- Restart keeps the disks in the drives.
- On a dual-screen device, saving a text setting closes the keyboard on the screen it was typed on, and opening a game's page from a search no longer leaves the search field over its settings.
- Manage library can group a game's loose disks into one game.
- A disk picked from outside the library, such as from Downloads, has a working copy of its own.
- Disk images in a ZIP that compress very well, such as a CD's silent audio track, are no longer refused.
- Working copies, saves and imported files reach storage before they take effect, so an interrupted write keeps the old ones.
- Import all from a folder also finds firmware files inside a ZIP in that folder, such as a MAME BIOS set.

Install over v1.4.3 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
