# v0.1.0-test.1

The first test build of KairoST, for Atari ST games. It is not published to Google Play.

- Runs Atari ST floppy games (ST, MSA, STX, DIM) and programs from their own folders.
- Games start on EmuTOS, which comes with the app, or on TOS images from your own machine, recognized by their version under any name.
- Skip memory check, on by default, and machine settings for the model, memory, monitor and region.
- A game library with catalog titles, descriptions and artwork, from a folder of your games; archives are read in place.
- Controller, touch and on-screen keyboard controls, with researched defaults and a button mapping for every game.
- Save states, and per-game settings that override the all-games ones.

Games are not supplied. Both APK variants have the same features.
