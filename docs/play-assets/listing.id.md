# Google Play listing: Indonesian (id)

- **App name:** KairoST

## Short description

Mainkan game Atari ST Anda di Android dengan kontrol sentuh atau gamepad.

## Full description

KairoST memungkinkan Anda memainkan game Atari ST milik Anda sendiri di Android. Tambahkan image disk atau folder program Anda, pilih game dari pustaka, lalu mainkan dengan gamepad atau kontrol di layar, termasuk keyboard Atari ST. Di handheld dua layar, game dan kontrol dapat ditampilkan di layar terpisah.

Game tidak disertakan. Sebagian besar game berjalan dengan EmuTOS bawaan; beberapa memerlukan TOS asli dari mesin Anda sendiri.

Anda juga dapat mengunduh aplikasi yang sama secara gratis dari GitHub Releases KairoST. Versi Google Play memiliki fitur yang sama.

KairoST adalah proyek independen yang menggunakan Hatari dan EmuTOS.
