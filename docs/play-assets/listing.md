## Short description

Play your Atari ST games on Android with touch controls or a gamepad.

## Full description

KairoST lets you play your own Atari ST games on Android. Add your disk images or program folders, pick a game from the library, and play with a gamepad or on-screen controls, including an Atari ST keyboard. On a two-screen handheld, the game and controls can use separate displays.

Games aren't included. Most games run with the included EmuTOS; a few need the original TOS from your own machine.

You can also download the same app free from KairoST GitHub Releases. The Play version has the same features.

KairoST is an independent project using Hatari and EmuTOS.
