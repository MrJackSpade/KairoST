# Google Play listing: Korean (ko-KR)

- **App name:** KairoST

## Short description

Atari ST 게임을 터치 컨트롤이나 게임패드로 Android에서 플레이하세요.

## Full description

KairoST로 가지고 있는 Atari ST 게임을 Android에서 플레이할 수 있습니다. 디스크 이미지나 프로그램 폴더를 추가하고 라이브러리에서 게임을 고른 다음, 게임패드나 Atari ST 키보드를 포함한 화면 컨트롤로 플레이하세요. 화면이 두 개인 휴대용 기기에서는 게임과 컨트롤을 서로 다른 화면에 표시할 수 있습니다.

게임은 포함되어 있지 않습니다. 대부분의 게임은 포함된 EmuTOS로 실행되며, 일부 게임에는 가지고 있는 실제 기기의 오리지널 TOS가 필요합니다.

같은 앱을 KairoST GitHub Releases에서 무료로 다운로드할 수도 있습니다. Play 버전에도 같은 기능이 있습니다.

KairoST는 Hatari와 EmuTOS를 사용하는 독립 프로젝트입니다.
