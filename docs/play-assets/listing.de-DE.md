# Google Play listing: German (de-DE)

- **App name:** KairoST

## Short description

Spielen Sie Ihre Atari-ST-Spiele auf Android mit Touch-Steuerung oder Gamepad.

## Full description

Mit KairoST spielen Sie Ihre eigenen Atari-ST-Spiele auf Android. Fügen Sie Ihre Datenträgerabbilder oder Programmordner hinzu, wählen Sie ein Spiel aus der Bibliothek und spielen Sie mit einem Gamepad oder der Bildschirmsteuerung, einschließlich einer Atari-ST-Tastatur. Auf einem Handheld mit zwei Bildschirmen lassen sich Spiel und Steuerung auf getrennte Displays verteilen.

Spiele sind nicht enthalten. Die meisten Spiele laufen mit dem enthaltenen EmuTOS; einige brauchen das originale TOS von Ihrem eigenen Gerät.

Sie können dieselbe App auch kostenlos über die GitHub Releases von KairoST herunterladen. Die Version bei Google Play hat dieselben Funktionen.

KairoST ist ein unabhängiges Projekt auf Basis von Hatari und EmuTOS.
