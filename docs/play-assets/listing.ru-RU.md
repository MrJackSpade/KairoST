# Google Play listing: Russian (ru-RU)

- **App name:** KairoST

## Short description

Играйте в игры для Atari ST на Android с сенсорным управлением или геймпадом.

## Full description

KairoST позволяет играть в ваши собственные игры для Atari ST на Android. Добавьте свои образы дисков или папки с программами, выберите игру в библиотеке и играйте с геймпадом или с экранным управлением, включая клавиатуру Atari ST. На портативных устройствах с двумя экранами игру и управление можно вывести на разные экраны.

Игры не входят в комплект. Большинство игр работают с прилагаемой EmuTOS; некоторым нужна оригинальная TOS с вашего собственного компьютера.

Это же приложение можно бесплатно скачать в GitHub Releases KairoST. В версии из Google Play те же возможности.

KairoST — независимый проект на основе Hatari и EmuTOS.
