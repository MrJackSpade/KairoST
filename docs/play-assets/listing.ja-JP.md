# Google Play listing: Japanese (ja-JP)

- **App name:** KairoST

## Short description

Android で、お手持ちの Atari ST ゲームをタッチ操作やゲームパッドで遊べます。

## Full description

KairoST は、お手持ちの Atari ST ゲームを Android で遊べるアプリです。ディスクイメージやプログラムフォルダを追加してライブラリからゲームを選び、ゲームパッドまたは画面上のコントロール（Atari ST キーボードを含む）で遊べます。2 画面の携帯ゲーム機では、ゲームとコントロールを別々の画面に表示できます。

ゲームは含まれていません。ほとんどのゲームは同梱の EmuTOS で動作しますが、一部のゲームにはお手持ちの実機のオリジナル TOS が必要です。

同じアプリを KairoST の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

KairoST は、Hatari と EmuTOS を使った独立したプロジェクトです。
